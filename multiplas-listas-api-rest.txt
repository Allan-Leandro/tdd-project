Antes, o site só tinha uma lista de tarefas, e era a mesma para todo mundo
Agora vamos fazer o site permitir várias listas diferentes, cada uma com seu próprio endereço na internet (tipo /lists/1/, /lists/2/).
Isso é parecido com uma API REST: cada lista tem um endereço só dela, então o site sabe exatamente qual lista mostrar quando alguém acessa aquele link.
